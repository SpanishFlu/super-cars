# Super Cars

A simple static website with three pages:

- `index.html` — home page
- `news.html` — car news
- `contact.html` — contact page

## Run locally

Open `index.html` in a browser, or serve this folder with a local development server.

The site uses external image URLs and Font Awesome. An internet connection is required for those resources.

## Contact form

The contact form currently points to `action_page.php`, but that backend file is not included. The form UI will display, but submissions need a server-side endpoint to work.
